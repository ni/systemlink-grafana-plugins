# Systemlink Work Orders data source

> **Note:** This data source is deprecated and will soon be removed. Please use the _SystemLink Work Items_ data source instead. It supports work orders along with all other work item types. For more information, refer to [Creating a Work Item](https://www.ni.com/docs/en-US/bundle/systemlink-enterprise/page/creating-a-test-plan.html).

This is a plugin for the Work Orders from the Work order service. It allows you to:

- Visualize workorders metadata and its count on a dashboard
