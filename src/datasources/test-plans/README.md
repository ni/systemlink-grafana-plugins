# Systemlink Test Plans data source

> **Note:** This data source is deprecated and will soon be removed. Please use the _SystemLink Work Items_ data source instead. It supports test plans along with all other work item types. For more information, refer to [Work Items data source](https://www.ni.com/docs/en-US/bundle/systemlink/page/work-items-data-source.html).

This is a plugin for the Test Plans from the Work order service. It allows you to:

- Visualize test plans metadata and its count on a dashboard
