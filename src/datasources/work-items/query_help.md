### SystemLink Work Items data source

The _SystemLink Work Items_ data source allows you to display work item properties from different work item types in dashboards.

### Key Features

- **Display work item properties**: Display various properties of your work items directly in your dashboards. These properties include **State**, **Assigned to**, **Due date**, and **Workspace**, across work item types such as **Work orders**, **Test plans**, **Job**, **Maintenance**, **Calibration**, **Reservation**, and **Transport Order**.
- **Custom Queries**: Create custom queries that filter and sort work item properties based on specific query conditions. These queries allow you to retrieve the most relevant work item information.

### Example Queries

For queries that use the _SystemLink Work Items_ data source, refer to the following examples:

- **List all work items in particular state**: Retrieve a list of all work items in a particular state (for example, **New**) along with their properties.
- **Count of work items**: Retrieve and display a count of work items filtered by various query conditions.
