### SystemLink Work Items data source

The _SystemLink Work Items_ data source allows you to display work item properties from different work item types in dashboards and derive insights.

### Key Features

- **Display work item properties**: Display key work item information directly in dashboards, including work item details, timeline information, resources, and custom properties. Examples include **State**, **Assigned to**, **Workspace**, **Due date**, **Created at**, **Updated at**, **Assets**, **DUTs**, **Fixtures**, and **Systems**, across work item types such as **Work orders**, **Test plans**, **Job**, **Maintenance**, **Calibration**, **Reservation**, and **Transport Order**.
- **Display total count**: Display the count of work items that match the selected type and query conditions.
- **Custom Queries**: Create custom queries that filter and sort work item properties based on specific query conditions. These queries allow you to retrieve the most relevant work item information.

### Example Queries

For queries that use the _SystemLink Work Items_ data source, refer to the following examples:

- **List work items in a particular state**: Retrieve work items in a particular state (for example, **New**) along with their selected properties.
- **View test plans by workspace or product**: Retrieve test plans filtered by workspace, part number, or other properties to review relevant testing activity.
- **Track work item progress**: Group work items by state to visualize progress across work orders, test plans, jobs, maintenance, calibration, reservations, or transport orders.
- **Review assigned work**: Display work items grouped by assignee and state to understand operator workload.
- **Track upcoming or overdue work**: Filter work items by planned start date, due date, or other timeline fields to identify work that is due soon or past due.
